# Spin / Noodles v6：Cherchi 正式求解 + CGAL 独立对照的模拟验收实施规划

**版本：** 2026-10-16 · 评审候选 · 不修改 GitHub  
**项目分支：** `spin-it-strict-computational-v2`；上一次已确认的远端提交 `a17ff49cd8a1e6e8b388bc591410bda56d67c28a`。运行检查点另有旧基线 `b0a13e3f7050630e84e3fbe19e7cf4004540a06e`，不得将其视为新分支重构建。  
**最终目标：** 重建 Noodles v6 在 Faster 二次曲面路线下得到实际收敛的材料模型、独立几何/质量矩核验、可复现的数值结果，以及由该结果的真实物理量驱动的无持续电机外力的陀螺旋转模拟。**制造/切片/实物验收后置**。作者原始 CAD 完全复现不在此阶段承诺范围。

基线集合语义：`F = S`（79 根管＋中心连接＋转轴等共 81 固定部件的并集），`E` 为椭球设计包络，`D = E \ F` 为待优化材料域，`A = E ∪ F` 是初始全填充整体，`K = E ∩ F`、`R = F \ E` 为独立核验用分解。**不存在必须保留的完整椭球外壳。**

## 2. 不可妥协的技术约束

1. **正式求解布尔后端必须是 Cherchi**。特别是 Newton 每次求值涉及的 `D ∩ Q(q)`、`D \ Q(q)` 与实际源面/来源追踪；不允许失败时静默回退到 CGAL、体素、手工雕刻或近似 SDF。
2. **CGAL 可以用于一次性输入精确并集和独立验证**。若 Cherchi 现有接口不支持 union，不能为了强求全流程 Cherchi 而伪造 union；冻结输入已由 CGAL 构造，然后把几何作为 Cherchi 求值输入。生产/验证角色在日志中显式标注。
3. 质量与导数基于**实际 Cherchi 返回的材料和源面**。采用 GMP 精确质量矩积分，不用 CGAL 数值替代 Cherchi 的导数判定；CGAL 只作独立对照。
4. 论文目标、权重、约束和冻结的停止准则未经单独评审不变。源数据登记中的 `raw_residual_tolerance=1e-12` 等参数要由代码验证实际含义。
5. 外观相似性是额外验收维度，不准用事后删壳/裁面、替换物理量、预设最终双曲面或改标记造出 PASS。
6. 每个阶段均保持失败记录；无真实运算终态不宣称成功。**没有 GitHub commit / push / PR / 远程修改**，直到收到针对具体成果的明确操作批准；“认可技术方案”不等同于“授权推送”。

## 3. 必须落地的生产/独立双路径架构

```text
冻结 v6 源模型：81 个固定部件 S + 椭球包络 E
        │
        ├── 输入构造【离线 CGAL】→ F, D=E\F, A=E∪F → 源身份与 SHA-256
        │                                          │
        │                                          └── 独立精确实体/分区证明
        ▼
Cherchi 正式求值（每个 Newton 参数 q）
    Q(q) ← 原 Faster 二次曲面 + 正式源面映射
    R(q) = D ∩ Q_material(q)
    C(q) = D \ R(q)
    M(q) = F ∪ R(q)  （可在不重叠前提下作质量矩相加）
        │
        ├── 实际交点与源三角形/布尔出生来源
        ├── GMP 10 个质量矩 + 固定材料质量矩
        ├── 光滑分支 Jacobian；来源切换单独报告
        ▼
Faster 原生 Newton（登记初值/阈值） → 合格终态 q*
        │
        ├── Cherchi 同次终态材料 → 实体、分区、OBJ 导出、重载
        ├── 独立 CGAL 集合与质量矩核验（不作为优化中的回退）
        └── 原始/优化后真实质量、重心、完整惯量
                   ▼
           动力学模拟 + 预登记工况 + 时间步一致性 + 轨迹视频
```

**重要接口注意点：**旧 Cherchi 烟雾测试曾显式拒绝 `union` 操作，故优先把 Cherchi 应用到 `intersection/difference` 的正式可变域求值；固定部分 `F` 与优化保留部分 `R` 的体积内部不重叠时，质量矩可准确相加，但生成可打印的最终有界整体仍需经过独立几何构造与审计。共享界面不能双计、不能因为界面重合而出现错误材料分类。若真实求值接口的 mesh/coord/provenance 数据契约不支持开放域，先扩展适配层，绝不虚构 Cherchi 已支持的功能。

## 4. 阶段关卡、修改范围与验收结果

### C0 — 冻结并核对最新代码/运行环境（目标：本地独立开发工作副本）

**任务：** 列出最新分支与旧检查点差异；记录主扩展、Cherchi 桥、GMP/MPFR/CGAL、Python 版本和 ABI；CMake 先配置再编译，消除过期 `build.ninja` 与加载器路径问题；禁止在没有可核实二进制身份时启动全量求解。

**通过条件：** 真实新工作副本目标构建/加载成功，运行 Cherchi 真实小型 intersection/difference、非法输入拒绝与 GMP 积分；与旧 P0 8 项小型结果做回归。生产 Cherchi 的来源与哈希记录明确。

**交付：** `C0_build_manifest.json`、`C0_build.log`、`C0_native_smoke.json`、增量 diff、失败记录。

### C1 — 补齐 v6 输入合法性（保留既有 CGAL 结果）

**任务：** 复用冻结的 6 份有理实体；完成所有未通过的实体 F/A/K/R 的独立合法性、方向、0/1 有界实体、内外材料分类、共面与退化检查；审查开放设计域 `D` 与初始外表面相交处的几何契约，必要时给定反例；确认 81 固定部件及转轴/连接实际保留。

**通过条件：** 六个实体审计均通过，三项表面链恒等式继续为零，合法实体前提成立，材料嵌套和开放域语义对照通过；若局部非法，记录精确失败面/状态、最小修复并重新出具冻结身份，不能只改判据。

**交付：** `C1_input_admission.json`、源输入 SHA-256、局部失败见证/重放、新旧固定壳外观对照，必要时 `v6.1` 输入版本。

### C2 — Cherchi 正式后端适配，禁止 CGAL 进入迭代

**任务：** 审计现有 `verification.cherchi_inprocess` / `_cherchi_core_boolean` 的真实 API 和来源；新增 `NoodlesCherchiEvaluator` 或等价隔离适配，不引入新的抽象名称强制覆盖生产代码。`solve.py` 的计算热路径不再实例化 `CgalReynoldsMap`。准确传递 D、二次曲面、材料侧、源面出生/交点来源、输出几何、错误类型及材料标签。不能通过仅更改 profile 名称来伪装后端切换。

**通过条件：** 小型和缩小规模 Noodles 几何的 Cherchi intersection/difference 实际运行，集合与独立 CGAL 相等，非法/分支情形真实 fail-closed；日志可以证明每次优化试探真正执行的是 Cherchi，没有 CGAL fallback。需要在真实 v6 83,408 面 D 上做至少一个登记起点的可行求值并保存操作数。

**交付：** 适配层最小补丁、`C2_backend_identity.json`、测试集、Cherchi-CGAL 差异 JSON 与失败重放操作数。

### C3 — 质量矩和 Jacobian 严格对照（数值入口放行关卡）

**任务：** 实际 Cherchi 材料上的十个有理质量矩以 GMP 精确积分，F 与 R 在共享界面处消去/避免体积重复，按冻结 SI/模型单位与坐标系转换；二次曲面随 q 变化的源面和交点速度按出生来源推导；对至少原始登记起点、光滑内点以及已出现过的困难来源切换状态做独立差分/高精度/CGAL 集合交叉检查。

**通过条件：** 十个质量矩、静态导数和有效光滑状态的方向导数满足现有冻结检查门槛；拓扑与来源切换不伪装为可微，Newton 能按已有规则回溯或拒绝；所有失败能与真实状态及输入 hash 对应。

**交付：** `C3_moment_comparison.json`、`C3_jacobian_report.json`、来源表、可重放状态快照、诊断与正式求值耗时分开统计。

### C4 — 正式 Faster Newton：一次成功 → 登记覆盖 → 独立重放

**任务：** 先冻结初值/种子/权重、求解预算/残差/几何规则，再运行 Cherchi 正式求值 + GMP 积分 + 原生 Faster Newton。先 seed 0 定位可复现失败，再完成 seed 1 与至少一次成功案例独立重放。不能因慢而降低 residual、缩小登记模型、跳过真实 Boolean；诊断缩模只用于故障定位。

**通过条件：** 有正式 `CONVERGED`（不是仅 `candidate`）并通过原残差、约束、无回退后端、终态材料/求值来源同次一致；种子覆盖与独立重放形成可复核记录。若有 seed 失败，按“部分通过”报告，不隐藏失败。

**交付：** `C4_native_result.json`、全部 seed trace、终态 q、原生/CGAL 独立检查、失败重放、完整时间分解。

### C5 — 最终材料、几何与论文外观对照

**任务：** 按 `M(q*)=F∪R(q*)` 导出真实整体，保留 fixed/retained/removed 分区、共享界面及有理权威表示；独立重载、方向/闭合/自交/连通/材料漏失检查及数值质量矩；从同一真实终态生成多视角＋剖面，对照论文 Noodles 图示，确认连续管束可见、没有永久椭球壳。

**通过条件：** 最终整个可见 OBJ 严格来自同次 Cherchi q*，CGAL 等独立几何核验、质量矩及重载一致；外形符合预先登记的论文重建相似性要求。如果外形不符，应追查输入设计或优化目标，并在另一个重新登记的输入版本重跑 C1—C5；不在导出端事后手工改面。

**交付：** `complete-mm.obj`、`fixed-mm.obj`、`retained-mm.obj`、`removed-mm.obj`、`delivery.json`、`reload-check.json`、多视角/剖面图、来源哈希。

### C6 — 面条专用动力学仿真（本阶段最终目标）

**任务：** 使用同一最终材料的 SI 质量、重心、完整惯量和有效接触几何，建立面条尖端与平面的刚体接触旋转模拟。原始输入与优化后使用相同初始角速度、初始倾角、接触/摩擦/步长与观测时长；初始角速度施加后**无持续电机、无外部姿态锁定**。验证求解器稳定性、数值收敛、接触可靠性；生成真实轨迹驱动的动画，而不是预定义旋转。

**通过条件：** 预先登记的每组仿真场景完成；优化后相对于未优化基线在所选稳定性指标上表现符合登记目标，时间步一致性通过；质量/惯量/模型哈希与 C5 完全对应，视频由实际轨迹重建。不能靠调整摩擦直到视频漂亮才宣称论文等效。物理参数未标定时仅报告“该假设场景下的模拟通过”。

**交付：** `C6_physics_manifest.json`、场景与参数 JSON、原始/优化后轨迹 CSV/NPZ、物理时间步收敛图、视频、计算摘要、失败工况记录。

### C7 — 制造与实物（本次明确延期，不阻挡 C6）

Bambu Studio 切片、最小可打印特征、装配/材料及实物打印旋转另立阶段；模拟通过不自动赋予制造通过。

## 5. 进度控制与交付审批

**每个阶段只授予以下状态之一：** `NOT_STARTED`、`RUNNING`、`PASS`、`FAIL`、`BLOCKED`；较小回归 PASS 不提升为下一阶段整体 PASS。上游失败时依赖阶段不启动；诊断演示结果另标 `DIAGNOSTIC_ONLY`。

每次阶段交付的固定组成：

- **代码增量**（单独 patch / zip），逐文件说明修改原因、涉及接口和对现有主线的影响；不覆盖已有已验证结果。
- **证据**（实际命令、stdout/stderr、退出码、单测与原生结果、完整源/二进制/输入哈希），失败也保留。
- **成果对象**（若有：几何/有理 JSON/最终 OBJ/轨迹/视频）；模型和求解身份必须对应。
- **中文阶段报告**：完成、不完整、失败、下阶段准入条件；性能报告按构造、Cherchi 求值、GMP、Newton、终态重载、仿真分账。

**用户确认制度：** 在聊天中先交付阶段成果供审阅。用户批准技术成果可授权继续下一阶段，但任何 GitHub commit/push/PR 都需要**针对具体变更的单独明确批准**。没有授权默认保持在线/本地候选，不写远端。
