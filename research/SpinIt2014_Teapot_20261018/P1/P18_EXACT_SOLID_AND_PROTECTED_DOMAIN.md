## 1. 补足了 P17 的相邻三角形与嵌入性缺口

P17 的有向边界恒等式只说明三角链抵消；非相邻面的浮点 SAT 检查也不能排除所有相邻面非法接触。
P18 在原始 OBJ 索引上检查闭合边、一致朝向、顶点 link 单环、唯一坐标索引、无重复面、无未使用顶点及精确非退化。
随后穷尽全部闭 AABB 候选对，要求两个三角形的交集**恰好等于**其共享的组合顶点或边。

| 保存材料 | 三角面 | 全部 AABB 候选对 | 无共享顶点 / 共享一个 / 共享两个 | 非法交集 |
|---|---:|---:|---:|---:|
| M | 7558 | 56504 | 9348 / 35819 / 11337 | 0 |
| F | 8198 | 61888 | 10042 / 39549 / 12297 | 0 |
| D | 640 | 5384 | 694 / 3730 / 960 | 0 |

相邻候选排除数为 **0**。不同精确平面上的共享边对由解析定理检查：两个平面的交线是该公共边的支撑直线，每个非退化三角形与该直线的交集恰为该边。
其他候选计算精确三角形交集；共面情形执行有理凸裁剪，非共面情形计算公共交线上的精确区间。
所有候选都进入其中一条检查路径，结果保存计数及候选索引流 SHA。

原始 binary64 坐标先转成对应的精确有理数，再统一提升为任意精度整数。
几何判断不使用 epsilon；输出中的浮点值只用于阅读。
近零行列式的浮点符号问题可参见 [Shewchuk 的原始说明](https://www.cs.cmu.edu/~quake/robust.html)；本阶段使用的是这里独立实现的整数/Fraction 判定，不调用 CGAL，也不重建 Cherchi 原生隐式点。

## 2. 从曲面证明推进到实体分区证明

主程序组合了以下独立事实，不能省略其中的嵌入性或包含性前提：

1. M、D 各有一个紧致、嵌入、闭合、定向一致的二维流形边界；允许非零亏格，不要求拓扑单连通。
2. 精确有向体积为正，固定各自的外向朝向。
3. M/D 的所有跨网格三角形对接受闭 AABB 分离；候选数为 0，两个表面严格不接触。跨网格不会按相同数值索引排除面。
4. 精确射线确认中心 `C=(0,0,binary64(0.67))` 在 M 内；遇到边、顶点或共面歧义时整条射线丢弃并重新选择，不做浮点微扰。
5. 下面的包围球证明整个 D 在 M 内，另以 D 的一个边界点在 M 内作交叉核验。
6. F 恰有两个分量，逐 facet 等于 `+M` 和 `-D`，没有隐藏的正反重复面抵消；精确体积亦满足 `V(M)=V(F)+V(D)`。

由紧致嵌入边界的内外分离及正确朝向，可定义保存坐标下的有界 regular closed solids。
F 的两个分量恰表示 M 去除 D 内部后的边界，因此得到：

- `F ∪ D = M`；
- F、D 没有正体积交叠；共享的内腔边界允许存在；
- D 严格位于 M 内部。

这比十矩等式更强，但仍不替代 W0 M6 所要求的真实原生 material-region 谓词。
P17 历史报告中的较弱标志没有被改写；本阶段新增的是范围明确的
`saved_repaired_solid_partition_certified=true`。

## 3. 外表面间距的全域有理下界

计算覆盖 M 的全部 7558 个三角面及 D 的全部 320 个顶点：

- 精确求 `min distance(C, each M triangle)^2`，包含面内投影、边和顶点情形；
- 精确求 D 顶点到 C 的最大距离平方；凸球包含所有 D 三角面，有界 D 也被其包含；
- 用整数平方根构造有理上下界，而不以浮点开方作证明。

实际得到：

```text
distance(C, boundary M) >= 0.523083796 reference unit
enclosing radius(D,C)   <= 0.200000002 reference unit
clearance(D,boundary M) >= 161541897/500000000
                       = 0.323083794 reference unit
```

中心在 M 内且上面的严格正间距成立，所以整个包围球及 D 均在 M 内。
按 P17 的 `0.025 m/reference unit` 提案，间距下界约为 **8.07709485 mm**。
精确 SI 下界也保存在 JSON；它按该 binary64 尺度的精确有理值换算。

这是该 D 到 M 外边界的距离下界。它不证明 Teapot 的每一处最小壁厚、打印可行性或结构强度。

## 4. 原轴杆保护存在真实失败，不能由单点 witness 代替

原轴杆来自 `P17_material_case/source/shaft-reference.obj`，其 SHA-256 为
`65d794715d580ebab231716669e25d79fea7f353da35c96d4a54f1779dc7e9f0`。
D 的 SHA-256 为 `1d4a0673e9297d95adfb5722158ba1d859a83099046d01116a2b363cb3cb386b`。

P18 从原轴杆的实际 OBJ 验证：D 的全部高度范围
`[0.4794636162158699, 0.8605363837841301]` 严格位于轴杆的常截面段
`(binary64(0.13), binary64(1.71))` 内。
上下环是完全相同的 32 边凸多边形，64 个实际侧三角面逐一覆盖相应矩形壁；开放高度带内不存在额外轴杆表面。
轴杆本身也通过独立嵌入闭合曲面审计及内部点检查。

对 D 的全部 **640** 个三角面执行 32 半平面的精确裁剪后发现：

- **74 个顶点**严格位于原轴杆开内部；
- **283 个三角面**具有原轴杆严格内部点；
- 反例包含精确原三角面、重心权重、精确点以及全部 32 个正半平面符号。

首个面反例为零起始 face **288**。最小正半平面符号为：

```text
92816140363298695 / 2658455991569831745807614120560689152 > 0
```

它是半平面表达式的符号值，不是以米为单位的穿透深度。
结合同一 D 的嵌入有界实体证书，D 的边界进入轴杆开内部意味着二者有正体积交叠。
因此，本轮既证明材料分区成立，也证明**这个可删域没有严格保护完整原轴杆**。
几何很接近接触不允许被改写为精确无交叠；本轮没有修改任何顶点来消除反例。

程序还严格证明，在原轴杆常截面段内，半径
`149277709/2500000000 = 0.0597110836` reference unit
（尺度提案下约 **1.49277709 mm**）的保守轴心圆柱不会被 D 删除。
它利用所有 D 表面的 XY 投影距离下界和一个在 D 外的轴心锚点。
这个 core 证书不等于完整原轴杆获保留，也不自动证明原轴杆整体包含于 M 或 F。

```bash

  --packet "$P1/P17_material_case" \

```

审计拒绝覆盖已有报告；verify 重算全部事实，只忽略运行耗时。
改动精确分数、源码 SHA、见证、批准标志或布尔类型都会导致重算不一致。
所有输入已随 P17 保存，本轮不依赖已过期工件下载来重算 P18。

测试包含独立解析多面体、非 dyadic 交点、2^-100 级别的分离/穿透、共享顶点遮掩的交叠、错向内腔、正间距但中心在外的反例，以及真正的 74/283 轴杆失败。
实际最终本地结果见测试回执。新增独立 P18 CI 作业执行全 73 项且拒绝跳过，再生成新报告，并分别重算 Git 报告和现场报告。
只有实际观测的失败状态、合法分区、74/283 反例及所有未准入标志同时一致，CI 才接受科学拒绝退出码 2。

P18 证明程序不运行新的原生布尔、优化或 MuJoCo。既有工作流仍可能重跑其旧原生及 MuJoCo 诊断作业，它们不构成本轮优化成果。
